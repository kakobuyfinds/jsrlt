How to compare listings before ordering

Save one row per color and size. Include the seller URL, quoted price, measurements and the date you checked them.

What to check

  1. Fit and variant. For shoes, record the size system and check whether the seller reports foot or insole length. For clothing, compare garment width and length against a piece you own.
  2. Seller link and agent support. Open the CAFANS listing, find the original seller link, and confirm that PikoBuy can process that exact URL and variant before you pay.
  3. Warehouse photos. If your agent provides QC photos, compare the label, color and measurements with the option you ordered. Check the exchange deadline while the item is at the warehouse.
  4. Shipping quote. Compare quotes using the same destination, parcel dimensions and packaging. Ask how the carrier calculates billable weight.

PikoBuy spreadsheet FAQ

What is a PikoBuy spreadsheet?

It is a shopping shortlist that organizes product links, variants and prices for comparison. This guide uses a small selection of CAFANS listings as its starting catalog.

Do these listings work with PikoBuy?

Check each original seller link with PikoBuy for compatibility and ask about any product or shipping restrictions before placing an order.

What does the USD price include?

Each card shows the estimated item price displayed on CAFANS. Use your actual quotes for domestic delivery, agent fees, international shipping and any applicable taxes when calculating the full cost.

Where can I find QC photos?

Check the original listing for seller photos. Ask your agent whether it provides warehouse photos of your specific item and whether measurements can be included.
